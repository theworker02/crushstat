# crushstat

Crush timestamps and stat durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/crushstat/

## Install / run

```bash
git clone https://github.com/theworker02/crushstat.git
cd crushstat
node src/cli.js
node --test
```
